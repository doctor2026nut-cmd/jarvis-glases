```

       │
       ▼

 ├── T01: Веб-клиент (Mobile-first, Orb UI, Audio I/O, Web Speech) ── [Готов / На проверке Muse]
 ├── T02: Сервер-прокси (WebSocket / HTTP Relay) ───────────────────── [Muse]
 ├── T03: Интеграция Gemini Live API (Двустороннее аудио + Tool Use) ─ [Muse]
```

## Детализация Этапа 1 (Веб-прототип)

### T01. Веб-клиент (Готов / Ревью)
- Интерфейс оптимизирован под узкие экраны смартфонов (mobile-first, 100dvh).
- Индикатор состояния ассистента: Orb со статусами `sleeping`, `listening`, `thinking`, `speaking`, `error`.
- Динамический селектор устройств ввода (микрофон очков/гарнитуры) и вывода (динамик очков).
- Реактивная машина состояний и история реплик.

### T02. Сервер-прокси (Muse)
- Двусторонний WebSocket шлюз между мобильным браузером и внешними LLM API.
- Аудио-потоки PCM/Opus с низкой задержкой (Low-Latency Audio).
- Управление переменными окружения и сессиями.

### T03. Разговор Gemini Live (Muse)
- Подключение Gemini Multimodal Live API (Bidirectional Audio Streaming).
- Поддержка прерываний речи пользователем (barge-in).
- Регистрация Function Calling / Tool Calling в реальном времени.

### T04. База знаний I CLUB (Antigravity)
- Структурирование информации о клубе, регламентах, услугах, ключевых контактах.
- Подготовка лаконичных эмбеддингов/системных промптов для работы ассистента в контексте очков.

### T05. Инструменты чтения статусов (Antigravity)
- Описание JSON-схем инструментов для LLM (Tool Declarations).
- Модули чтения системных статусов, времени, батареи, текущей очереди задач, расписания и сетевого статуса.

### T06. Ручной чек-лист (Muse)
- Сквозное тестирование сценариев разговора, распознавания, переключения устройств и вызова инструментов.
