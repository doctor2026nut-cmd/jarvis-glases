# Jarvis — Glasses Assistant (Web Prototype)

Голосовой помощник для AI-очков. Прототип работает в мобильном браузере.

## Быстрый старт

```bash
# 1. Скопировать переменные окружения
cp .env.example .env

# 2. Запустить любой статический сервер, например:
npx serve .          # или python3 -m http.server 3000
```

Открыть `http://localhost:3000` на телефоне (или через DevTools → Mobile viewport).

## Структура

```
├── index.html          — главная страница (mobile-first)
├── css/
│   └── style.css       — стили: тёмная тема, orb-индикатор, чат
├── js/
│   ├── app.js          — точка входа, инициализация
│   ├── state.js        — реактивная машина состояний
│   ├── audio.js        — выбор микрофона и динамика
│   ├── speech.js       — распознавание речи (Web Speech API)
│   └── ui.js           — обновление DOM по состоянию
├── .env.example        — шаблон переменных окружения
└── .gitignore
```

## Состояния

| Состояние  | Цвет орба   | Описание                    |
|------------|-------------|-----------------------------|
| sleeping   | 🔘 серый     | Ждёт команды               |
| listening  | 🔵 голубой   | Слушает речь пользователя  |
| thinking   | 🟡 жёлтый   | Обрабатывает запрос (LLM)  |
| speaking   | 🟢 зелёный  | Озвучивает ответ            |
| error      | 🔴 красный  | Ошибка (нет доступа и т.д.)|
